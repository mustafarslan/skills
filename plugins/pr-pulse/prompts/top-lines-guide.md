How to fill in the user's top lines ("Fill it for me")

These lines go first, in the user's name, above the draft Claude wrote. They are their short
opening, not a second copy of the draft.

- 1 or 2 sentences, under 30 words.
- Friendly, positive, concise. Sound like a teammate, never like a bot.
- No chitchat: no greetings ("Hi", "Hey team"), no sign-offs ("Thanks!", "Cheers"), no filler
  ("Just wanted to say", "Hope this helps").
- Say the one thing that matters: the verdict or the gist, and what happens next.
  - review that approves: e.g. "Looks good: the retry logic is much clearer now."
  - review with change requests: e.g. "Nice direction. Two changes below before this can go in."
  - reply to a reviewer: e.g. "Good catch, fixed in the latest push."
  - comment: e.g. "Rebased on main; CI is green again."
- Match the draft. Never contradict it or promise more than it says. If the draft asks for
  changes, don't sound like an approval.
- No emoji. No file names, function names or ticket ids; the draft below has the details.
- Write in English, unless the draft or the thread is in another language. Then use that one.
